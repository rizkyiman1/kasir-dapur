# Tester Guide — Kasir Dapur Closed Testing

**App:** Kasir Dapur 1.0.0  
**Package:** com.kasirdapur.app  
**Kontak:** support@dapur-rasa.com

> Panduan ini dikirimkan ke tester closed testing Google Play.  
> Panduan lengkap dengan checklist 13 skenario ada di `CLOSED_TESTING_GUIDE.md`.

---

## Cara Bergabung

1. Klik link opt-in yang dikirimkan ke email atau WhatsApp Anda
2. Klik **"Become a tester"**
3. Klik **"Download it on Google Play"**
4. Instal seperti biasa

**Syarat perangkat:** Android 5.0 ke atas, minimal 50 MB storage tersedia.

---

## Cara Memulai

1. Buka app → layar splash "Kasir Dapur" muncul
2. Isi nama toko Anda (bisa nama fiktif untuk testing)
3. Buat PIN 4 digit
4. Masuk ke dashboard

---

## Yang Perlu Diuji

Ikuti urutan berikut selama sesi testing (30–60 menit):

| # | Skenario |
|---|---|
| 1 | Install & onboarding |
| 2 | Login & keamanan PIN |
| 3 | Tambah beberapa produk |
| 4 | Kelola stok produk |
| 5 | Buat transaksi penjualan |
| 6 | Proses pembayaran |
| 7 | Lihat struk |
| 8 | Coba mode offline (matikan WiFi) |
| 9 | Aktifkan kembali koneksi |
| 10 | Lihat laporan penjualan |
| 11 | Cek halaman subscription |
| 12 | Kunci / keluar sesi |
| 13 | Cek halaman Hapus Akun (tidak perlu dieksekusi) |

Panduan detail setiap langkah ada di `CLOSED_TESTING_GUIDE.md` → Bagian 3.

---

## Masalah yang Sudah Diketahui

Tidak perlu dilaporkan:

- **Harga paket Pro/Business belum tampil** — sedang dikonfigurasi
- **Fitur sinkronisasi cloud mungkin error** — backend dalam persiapan
- **Website dapur-rasa.com belum aktif** — dalam persiapan

---

## Cara Melaporkan Bug

Kirim laporan ke: **support@dapur-rasa.com**

Sertakan:
- Merk dan model perangkat
- Versi Android
- Langkah untuk mereproduksi masalah
- Apa yang terjadi vs. apa yang diharapkan
- Screenshot jika memungkinkan

---
